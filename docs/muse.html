How it works Report an issue
  1. Paste it into Muse and send.
  2. Tap Allow all, so it asks only once. There's no sign-up.
  3. Choose your chat messages or posts only. Your Psyche is ready in about 5 minutes.

PsycheAI installs only from app.psycheai.io (psycheai.io/muse is its short link), and every update is signed. Anything else isn't PsycheAI.

Prefer a connector? Paste Add a custom connector: https://app.psycheai.io/mcp. If it asks for a Client ID, use psycheai. Once it's connected, open PsycheAI. If Muse shows a Client ID box, type psycheai and tap Add.
