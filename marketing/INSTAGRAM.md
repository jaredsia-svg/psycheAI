# PsycheAI on Instagram: profile, captions and outreach

*October 2026. Copy for the launch reels. The finished videos, ready to post, and a cover for each are in
`marketing/reels/` (copied from `promo/out/`, which git ignores; rebuild with `npm run promo:shorts -- <reel>` and
copy again after a change). It lives outside `docs/`, so it is not served on the site. See `PLAN.md` for the
strategy behind it.*

Two rules run through all of it:

- **The export is the bottleneck.** Instagram takes hours to email someone their data, so every caption and
  auto-reply leads with *request it now, read it tonight*, and points to the step-by-step guide at
  psycheai.io/download-instagram-data.
- **Every claim stays literally true.** First Psyche Card free; the roast free with every card; one Ask PsycheAI
  question free; the full report paid. Files never leave the device; only a de-identified summary is analysed,
  and PsycheAI keeps no copy.

No pressure either way. Here's one of ours for a feel: [link]

Per-creator codes with caps already exist (`PSYCHEAI_PROMO_CODES=CODE:cap:lastday:percent`, and links can carry
`?promo=`), so each creator can get their own trackable code.
